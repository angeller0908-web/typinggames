# TypeQuest Web

Next.js 15 (App Router) + Tailwind + MDX, static-exported for Cloudflare Pages.

## Quick start

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static export to out/
npx serve out      # serve the build
```
