## How to play

This game uses a countdown typing format. Each prompt has a timer. Type the word or code before the countdown expires and keep the round alive. Most runs last about 75 seconds, which makes it easy to replay and compare results. It is best for short, focused sessions where reaction time matters as much as WPM.
