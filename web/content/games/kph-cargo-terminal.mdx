## A real KPH test, not a word game

KPH Cargo Terminal is a free **keystrokes-per-hour test** in the format data-entry employers actually use: numeric and coded entries, not sentences. The console shows two live meters — KPH and accuracy — that update with every keystroke, so you can watch your number move instead of waiting for an end screen. Key in each code exactly as shown (digits, dashes and decimal points included), and the next one slides into place.

## How the test works

Each run lasts about 75 seconds. The prompts are short data-entry codes — invoice-style numbers like `417-2096` or `62.40` — which is what 10-key and warehouse-terminal assessments measure. Your KPH is calculated the standard way: correct keystrokes divided by elapsed time, scaled to an hour. Replay a few rounds back to back and use the best of three; that's roughly how staffing-agency tests score it too.

## What counts as a good score

Entry-level data entry listings typically ask for **8,000–10,000 KPH**; experienced 10-key operators clear 12,000+ with 98%+ accuracy. Accuracy matters more than raw speed here — most employers cut off candidates below 95% no matter how fast they key. If your accuracy meter dips yellow or red in this test, slow down until it pins green, then rebuild speed.

## Strategy tips

Read the whole prompt before typing. Job-style rounds punish careless corrections. If a word feels unfamiliar, type it once for accuracy before trying to type it quickly. Clean repetitions build more useful speed than guessing, deleting, and retyping.
